## Features

- A hero with a clear "speak to a legal professional" call to action
- **Services for individuals and businesses**
- **Why choose us** trust signals: experience, client focus, clear
  communication, and confidentiality
- A **consultation** booking section and client testimonials
- **Legal pages**: privacy policy, terms, and complaints procedure
- A fully responsive, accessible layout

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

```
index.html          homepage
privacy-policy.html, terms.html, complaints.html
styles.css, policy.css, main.js
```

## Run locally

```bash
git clone https://github.com/dean1234533/Da-Law-Firm-Premium-Law-Firm-Website-Mockup.git
cd Da-Law-Firm-Premium-Law-Firm-Website-Mockup
```
